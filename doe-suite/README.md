# Experiment framework

Vendored copy of the open-source experiment framework used to run the Artemis evaluation on AWS EC2
(link omitted to keep the submission anonymous). It orchestrates the suites in `../doe-suite-config/designs/`
and runs the ETL pipelines that produce the paper's tables and plots. See the top-level `README.md` for usage.
